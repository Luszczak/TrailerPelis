## Visión general
- **Propósito:** Explorar trailers con una UI cinematográfica, micro‑interacciones fluidas y carga ligera.
- **Filosofía:** HTML semántico, CSS expresivo y JS modular. Performance sin sacrificar estilo.
- **Audiencia:** Cinéfilos, diseñadores de UI y devs que aman los detalles.
